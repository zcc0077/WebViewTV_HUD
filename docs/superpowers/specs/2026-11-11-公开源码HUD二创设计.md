# 公开源码 HUD 二创设计

用户确认以官方最后公开的 1.6 工程为基础，补齐已确认的全部 HUD 能力；不声称恢复闭源 3.0.1。首次安装默认自动全屏，尊重之后的用户选择。

## 工程与来源

保留现有仓库与官方 main 的提交历史，以双亲合并接入官方源码，不强推或删除仓库。默认工程为标准 Gradle Android 工程，构建不依赖原 APK、smali 或私钥。现有反编译版提交保留在历史中，README 明确两个实现的来源与功能边界。不修改仓库的可见性或为上游代码虚构许可证。

## 功能与边界

- 保持包名 com.vasthread.webviewtv.v2.hud、名称 WebView 电视 HUD。
- 自动全屏与后台播放默认开启，后台播放方式提供“小窗 / HUD”，默认 HUD；只有选择 HUD 才进入 display 2，小窗使用 Android 画中画，不申请悬浮窗权限。两个开关，可在设置页关闭，使用已有 auto_fullscreen、pip_enabled 偏好键。
- Home 离开应用时将实际播放器移到 display 2；只使用 (0,720) 开始的 728×190 HUD 区域。默认高 190，按视频比例决定宽度。缺屏或授权失败时恢复播放器并提供说明，不回落到仪表盘或主屏悬浮窗。
- 恢复应用时将播放器放回原父容器，保留播放；退出与销毁时移除窗口，释放页面和回调。权限设置与编辑弹窗不得触发 HUD 后台播放。
- HUD 设置使用实际的播放器尺寸/比例接口，不使用混淆字段反射。预览支持拖动、右下角缩放、滑条、保存、取消、恢复默认，持久化兼容 hud_window 的 x/y/height。
- 悬浮窗权限使用 framework/AppOps 及现有透明探测兜底，支持 API 28/30；仅通过系统设置申请，不修改系统配置。所有窗口操作在主线程。
- 恢复官方被置空的播放列表入口：合法公开网页播放与自定义列表，拒绝空 URL 和非法配置，不把未验证的直播站点可用性称为全部兼容。

## 验证

先验证默认值、HUD 几何、权限策略、前后台播放决策及列表边界的失败测试，再实现。运行 Gradle 单元测试、debug 构建与相关 Lint。模拟器验证首次启动、全屏设置、HUD 编辑保存/重开/取消、缺屏降级和恢复；能创建虚拟副屏时验证实际窗口移入与恢复。实车无需安装，本轮推送的是源码版，不能沿用原 APK 的实车验收结论。

## 本轮验证范围

保留原同一播放器迁移，不包含新建副屏播放器或网页重载。默认自动全屏、小窗/HUD模式、权限策略、窗口几何和编辑器可本地验证；本轮旧内核模拟器的视频像素采样未通过，不能以窗口高度190px推断视频像素已全高出图，源码版仍需实车确认。
